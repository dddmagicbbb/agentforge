# 공통 작업 규칙
- 답변·문서는 {{LANG}}, 코드 식별자는 영어.
- 커밋 메시지: `[에이전트] 작업ID 요약` (예: `[dev-1] T-101 주문 목록 조회`)
- 한 커밋에는 한 작업 ID만 담는다.
- 완료 보고 docs/report-<에이전트>.md
  | 작업 ID | 결과 | 변경 파일 | 테스트 | 남은 문제 |
- 비밀 값(키, 비밀번호)을 코드·문서·로그에 쓰지 않는다.

# 반려 사유 (하나라도 있으면 reject)
- 테스트 실패, 또는 상세 설계 6장의 테스트가 없음
- 담당 범위 밖 파일 변경
- 계약과 다른 요청·응답 형식
- 수용 기준 미충족, 오류 처리 누락, 비밀 값 하드코딩
# 기록 (docs/review/dev-N.md)
| 판정 | 파일:줄 | 문제 | 고칠 방법 |
- 지적은 고칠 수 있게 구체적으로. 취향 문제(이름 스타일 등)는 반려 사유가 아니다.

# 상세 설계 양식 (docs/design/detail/dev-N.md)
1. 담당 작업·기능 ID 목록
2. 파일 목록: 만들 파일 경로와 책임 한 줄 (모두 담당 범위 안)
3. 주요 함수·클래스: 시그니처, 입력 검증, 오류 처리
4. 사용하는 계약: 호출하는 API·제공하는 API (계약 파일의 이름 그대로)
5. 화면 상태(화면이 있을 때): 로딩/빈 값/오류/성공
6. 테스트 목록: 기능 ID별 수용 기준 → 테스트 이름
7. 계약·공통 모듈에 필요한 변경(있으면 구현 전에 멈추고 보고)
